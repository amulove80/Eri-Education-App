# Netflix Live Guess Game 🎬

A fun and interactive guessing game featuring popular Netflix movies and TV shows!

## Features

- **24+ Netflix Titles**: Includes popular series like Stranger Things, Squid Game, Money Heist, and movies like Red Notice, Bird Box, and more
- **Real-time Scoring**: Track your correct and wrong answers as you play
- **Beautiful UI**: Netflix-themed design with smooth animations
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Smart Answer Checking**: Case-insensitive matching for user-friendly gameplay

## How to Play

1. Open `netflix-game.html` in your web browser
2. Read the hint about a Netflix show or movie
3. Type your answer in the input field
4. Click "Submit" to check your answer or "Skip" to move to the next question
5. Try to get the highest score possible!

## Technologies Used

- Pure HTML, CSS, and JavaScript
- No external dependencies required
- Fully self-contained single-file application

## Quick Start

Simply open the `netflix-game.html` file in any modern web browser and start playing!
